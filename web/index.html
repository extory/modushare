자주 묻는 질문

클립보드 공유, 궁금한 점

모두쉐어는 무엇인가요?

모두쉐어(ModuShare)는 Windows와 Mac 사이에서 복사한 텍스트와 이미지를 공유하는 클립보드 동기화 서비스입니다. 데스크톱 앱으로 자동 공유하거나 대상을 선택해 보내고, 웹에서 복사 기록을 확인할 수 있습니다.

Windows에서 복사한 내용을 Mac에 붙여넣을 수 있나요?

두 기기에 모두쉐어 앱을 설치하고 로그인한 뒤 자동 클립보드 공유를 켜세요. Windows에서 Ctrl+C로 복사한 텍스트나 이미지를 Mac에서 ⌘V로 붙여넣을 수 있습니다. 반대 방향도 지원하며, 다른 계정 간에는 공유 관계를 설정해야 합니다.

자동 공유와 대상 지정 보내기는 어떻게 다른가요?

자동 공유는 상대 기기의 클립보드를 최신 복사 1건으로 교체합니다. 대상 지정 보내기는 선택한 기기의 수신함에 최근 10건을 보관하며, 사용자가 선택한 뒤 붙여넣습니다.

탐색기에서 복사한 파일도 자동 전송되나요?

현재 자동 공유 대상은 텍스트와 이미지 클립보드입니다. 탐색기나 Finder에서 파일 자체를 복사하는 것은 자동 공유 대상이 아닙니다. 텍스트와 이미지는 최대 5MB까지 공유할 수 있습니다.
